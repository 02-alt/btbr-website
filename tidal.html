FAQ
What is Tidal Mini Player?

A menu-bar mini player for the TIDAL desktop app. It shows the current track in your menu bar and opens a compact player with album art, a live progress bar, and previous / play-pause / next controls.

Do I need the TIDAL app?

Yes. It mirrors and controls TIDAL's own desktop app, so TIDAL needs to be running.

Does it need any permissions?

For everyday use, no. Controlling TIDAL in the background can use the macOS Accessibility permission, which you grant once.

macOS says it's from an unidentified developer — is that OK?

Yes. On first launch, right-click the app and choose Open to get past Gatekeeper. You only need to do this once.

Why did the track freeze when I played a video elsewhere?

macOS only tracks one “Now Playing” app at a time. If a browser video grabs that slot, TIDAL stops being reported — the player keeps showing the last TIDAL track until TIDAL takes the slot back. Controls only act while TIDAL owns it.

Does it run on Intel and Apple silicon?

Yes — it's a universal build for both. Requires macOS 13 or later, and it lives in the menu bar (no Dock icon).

How much does it cost?
