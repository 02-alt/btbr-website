FAQ

What is Claude Fuel?

A menu-bar app that shows how much of your Claude usage window is left as a retro fuel gauge, with a live refuel countdown and usage stats.

Where does it get my usage data?

It reads Claude Code's usage logs stored locally on your Mac. No login, no API key — nothing leaves your machine.

Do I need Claude Code for it to work?

Yes. Claude Fuel reads Claude Code's local usage files, so it only shows data if you use Claude Code on that Mac.

Why do I set my own “tank size”?

Subscription plans don't publish a token allowance, so you set the tank (your budget) for your plan in Settings. The gauge then fills your real consumed tokens against it.

What do the countdown and colors mean?

The menu-bar timer counts down to when your rolling usage window resets; green, amber and red show how much fuel is left.

Can I keep the gauge always on screen?

Yes — the Mini button pops the gauge into a floating, always-on-top window you can park in a corner. Pick from Silver, Graphite or Amber CRT themes.

What do I need, and how do I launch it at login?

macOS 13 or later. Move it to your Applications folder and open it; to start it automatically, add it under System Settings → General → Login Items.

macOS says “ClaudeFuel” is damaged and can’t be opened — is the download broken?

No — the app is fine. That's macOS Gatekeeper, not real damage. Claude Fuel isn't notarized through a paid Apple Developer account, so when you download it your browser tags it with a “quarantine” flag and macOS shows this misleading message.

Fix it in any one of these ways:
• Right-click (or Control-click) ClaudeFuel.app → Open → Open.
• If it still refuses: open System Settings → Privacy & Security, scroll down and click Open Anyway, then launch it again.
• If it still says “damaged”: open Terminal and run this line (adjust the path if the app isn't in your Applications folder), then open it normally:
xattr -dr com.apple.quarantine /Applications/ClaudeFuel.app

You only have to do this once — afterwards it opens normally.
