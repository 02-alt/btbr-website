FAQ

What is Encore?

A native macOS emulator that plays Game Boy Advance games — with a cartridge-shelf library, save states, game controllers, and a floating always-on-top play window.

What can it play?

Game Boy Advance, Game Boy Color and original Game Boy games. More systems, and an iOS version, are in the works.

Do I bring my own games?

Yes. Encore plays the .gba, .gbc and .gb game files you already own — it doesn't include or provide any games.

Can I keep playing while I work?

Yes. Pop the game into a floating, always-on-top window and park it in a corner while you do other things.

Does it save my progress?

Yes. Battery saves and auto-resume are automatic, and you can drop a manual save state at any moment and jump back to it later.

Can I use a controller?

Yes — game controllers and the keyboard both work. You can also set an ambient background sound like rain or storm while you play.

Is there an iOS version?

An iOS version is in the works — you can try it now through the public TestFlight beta.

What do I need to run it?

A Mac running macOS 15 (Sequoia) or later. If macOS says it can't verify the developer on first launch, right-click the app and choose Open.

What's new in this version?

The 1.1 update carries your library across your own devices over your private iCloud — your games and saves follow you, a clear “Receive” card flags an incoming game, and cartridges fly to the cloud when you send and drop away when you delete. Game Boy Color and original Game Boy support arrived in recent builds too.

What version is this?

1.1.0. Encore checks for a newer version on its own and points you to it when one is out, so you can always stay up to date.

How much does it cost?

Free.
